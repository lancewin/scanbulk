Permissions

This app only requests necessary permissions when you actively use related features:

Camera
  • When: Scanning feature
  • Purpose: Access camera for real-time scanning
  • Privacy: Frames are processed locally only, never uploaded to any server
Photo Library (Read)
  • When: Image scanning, album selection
  • Purpose: Select images from album for QR/barcode recognition
  • Privacy: Only reads images you actively select; recognition happens entirely on-device, no images or personal data uploaded to servers
Photo Library (Write)
  • When: Saving generated code images
  • Purpose: Save generated QR/barcode images to album
  • Privacy: Only writes app-generated images; operation is entirely on-device, no image data uploaded to servers
Network
  • When: Subscription purchase
  • Purpose: Connect to App Store for payment
  • Privacy: Used only for payment functionality

All permissions are optional and can be turned off at any time in system Settings.
